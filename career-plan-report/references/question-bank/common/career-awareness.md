# 题库：职业认知度校准（动态补问用）

> 触发条件：Q5 勾选了某个方向但 B4 评估发现匹配度存疑；或 Q5 与 Q6/Q2 信号矛盾（如勾了算法研究但数学相关技能弱）；或用户主动表示"想了解某方向"。
> 核心原则：**"想做什么"≠"知道这个职业实际是什么"**。兴趣与认知分开测量，认知盲区不惩罚，但要标注。
