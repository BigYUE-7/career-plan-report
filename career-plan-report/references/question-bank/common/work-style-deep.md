# 题库：工作方式深维（动态补问用）

> 触发条件：Q6/Q7/Q12/Q13 出现信号混杂（如技术 5 分但选了产品策划）、或 B4/B8 需要更细的行为维度做决策论证时。
> 设计原则：把"职业名称偏好"拆成四个独立行为维度——避免选项塑造结论。

## W1 自主性（single）

提示：你更喜欢哪种任务安排方式？

- 明确任务，按要求完成（路径清晰最安心）
- 有目标，但方法自己定（给我空间但不给我迷路）
- 只给方向，问题自己找（喜欢定义问题本身）
- 完全自主决定做什么（自我驱动型）
- 暂不确定

## W2 工作节奏（single）

提示：哪种节奏你能长期保持状态？

- 稳定、可预测（每天干什么基本知道）
- 稳定中有变化（大部分可控，偶尔新挑战）
- 经常面对新问题（每周都不一样才不无聊）
- 高频快速迭代（节奏快、两周一版）
- 极高强度短周期（冲刺式出成果）
- 暂不确定

## W3 人际程度（single，细化 Q12）

提示：一天工作中，你希望"与人打交道"占多大比例？

- 几乎独立工作（偶尔同步即可）
- 少量协作（每天几小时专注+少量沟通）
- 团队协作（一半时间在讨论对齐）
- 高频沟通（沟通就是主要工作）
- 主要做"人与人之间"的工作（销售/客服/HR 类）
- 暂不确定

## W4 结果类型（multi，勾 1~3 项）

提示：一天结束时，看到**什么结果**出现在自己手里最有成就感？（这决定你适合哪类岗位，比职业名称更准）

- 一段能跑的代码
- 一个训练好的模型
- 一件产品功能上线
- 一份被采纳的方案/报告
- 一个设计稿/视觉作品
- 一段视频/内容
- 一个解决掉的用户问题
- 一项研究结果/结论
- 一个被推动落地的项目
- 一笔成交/增长数据
- 暂不确定

> Agent 使用规则：W1~W4 与 Q6/Q7/Q12/Q13 交叉验证；冲突时以 W 维度为准（更具体、更难伪装）。B8 决策论证中引用 W 维度回答"为什么不适合某方向"。
