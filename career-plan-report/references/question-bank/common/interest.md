# 题库：兴趣来源与成就证据（动态补问用）

> 触发条件：基础卷 Q5/Q6 全选或勾"暂不确定"、Q8 价值勾选 ≥4 项（未收敛）、或 B4 方向矩阵发现候选不足。
> 用法：Agent 用 AskUserQuestion 抽 3~5 题（单轮 ≤4），标注"对话补录"，证据进 B3 画像与 B4 方向矩阵。

## A1 兴趣大类（multi，勾 2~4 项）

提示：抛开"能不能就业"，只问自己——你对哪些事情**天然**感兴趣（没人要求也会关注的那种）？

- 创造东西（从 0 到 1 做出点什么）
- 解决问题（面对难题就兴奋）
- 研究知识（搞清原理比会用更重要）
- 与人交流（认识人、聊想法有能量）
- 帮助别人（别人因你变好会满足）
- 组织协调（把人和事安排得井井有条）
- 表达观点（说清楚一件事很有成就感）
- 经营商业（对赚钱和生意模式敏感）
- 设计视觉（对好看的东西有执念）
- 写作/内容（表达和记录的冲动）
- 编程/技术（写代码本身就有乐趣）
- 动手制作（拆装、改造、上手做）
- 教学/指导（把会的东西讲给别人）
- 探索未知（对新领域有强烈好奇心）
- 暂不确定（希望报告帮我探索）

## A2 场景下钻（按 A1 勾选结果抽问，single）

提示：哪种**创造**最容易让你产生满足感？（若 A1 未勾"创造东西"则替换为对应大类的场景题）

- 做出一个软件/应用（别人真的在用）
- 做出一个硬件（看得见摸得着）
- 做出视觉作品（图/界面/视频被夸）
- 写出一篇文章（观点被认同）
- 设计一个产品方案（被团队采纳落地）
- 搭建一套完整系统（工程成就感）
- 解决一个现实问题（有人因你省了时间/钱）
- 做成一个商业项目（有人愿意付费）
- 其他/暂不确定

## A3 主动投入经历（开放题，最有价值的兴趣证据）

提示：过去 1~2 年，有没有一件事**没人要求你**，但你主动投入了大量时间？（哪怕看起来"没用"：自学某技术、做游戏、拆硬件、运营账号、研究 AI……）

作答：______（自由填写；其中哪件事最容易让你忘记时间？为什么？）

> Agent 使用规则：A3 的答案权重高于一切声明式偏好（Q6~Q8）——"实际怎么做"比"认为自己喜欢什么"更可信。B3 画像中单列"兴趣证据"行；B4 方向矩阵中若 A3 与 Q5 勾选冲突，以 A3 为准并在报告中说明。
