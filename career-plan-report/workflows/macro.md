# 宏观工作流：01 《XX领域职业能力调研报告》（产业—职业生态分析）

> 由 SKILL.md Step 0.5 路由进入。前置条件：Step 0 项目初始化已完成。
> **v1.2.0 定位升级**：宏观报告不是"招聘网站统计"，而是回答——**这个行业由什么构成、钱和价值在哪里流动、每个环节需要什么人才、能力需求正往哪里变化、个人从哪里进入**。产出物 = 一张行业职业地图，供微观阶段直接对照。

## 共同前置

- 所有产出写入 `<项目>/01-宏观调研报告/`。
- 用户启用了 AI 使用留痕 → 每阶段向 `00-AI工具使用记录.md` 追加记录；未启用则不做。
- 检索原则：每阶段 1~2 轮检索即可，优先权威来源（政府、协会、头部研究院）；检索不到的环节如实标注"未获取"，禁止编造。

## Phase 1 数据底座（M1~M9，随报告一体完成）

边检索边把结论沉淀到 `<项目>/01-宏观调研报告/底座结论.md`（模板 14 节，见文末）。六类核心信息：

| 数据层 | 要回答的问题 |
|---|---|
| 产业结构 | 这个行业由什么组成？ |
| 产业链 | 钱和价值在哪里流动？ |
| 岗位生态 | 企业现在招什么人？ |
| 区域分布 | 机会集中在哪里？ |
| 技能变化 | 企业需要的能力正在怎么变？ |
| 政策锚点 | 国家正在推动什么？ |

### M1 行业定义与边界
- 用一段话+一张结构图界定行业范围：包含什么、不包含什么、与相邻行业的边界。
### M2 产业结构
- 上游（基础层）/ 中游（技术平台层）/ 下游（应用层）各含哪些环节——列出环节清单，每个环节 1 句话说明。
### M3 产业链上下游（★核心）
- 上中下游细分到可对应岗位的颗粒度；每环节标注代表企业类型与价值量级（市场规模/增速，能查到就写）。
### M4 企业类型生态
- 该行业由哪几类玩家构成（如：巨头/独角兽/传统企业转型部门/中小企业/自由职业市场），各自的用人特点与岗位偏好。
### M5 岗位生态（环节 × 岗位 × 能力）
- **产业环节 → 企业类型 → 典型岗位 → 核心能力**四列表（宏观报告的核心产出表，微观 B4/B6 直接引用）。
### M6 技能需求变化
- JD 高频词变化、新兴岗位增速、萎缩岗位——从"岗位数量统计"上升到"能力需求迁移方向"。
### M7 区域分布
- 城市集群 + 增量城市 + 人才流向（沿用原有 china-map 方法）。
### M8 政策锚点
- 核心政策文件、时间线、政策→人才信号对照。

### M9 上下游传导分析（★核心，职业趋势的关键）
- 至少 2 条**传导链**：上游变化 → 中游反应 → 下游岗位影响。示例形态：
  `算力成本下降 → 推理成本下降 → AI 应用数量增加 → 应用开发岗位增加 → Agent/工程化能力升值`
- 每条链注明证据（成本数据/产能数据/招聘数据）与对个人选择的含义（哪类能力未来 2~3 年升值/贬值）。
### M10 人才链（职业位置观）
- 画出该行业的典型人才成长链（如：算法工程 → 模型工程 → 应用工程 → AI 产品 → 行业应用），说明个人通常从哪个位置进入、向哪些位置迁移——**职业是产业链上的一个位置，不是孤立岗位**。
### M11 职业进入路径
- 本科/硕士/转行/实习各自的主要入口环节；普通本科最友好的 2~3 个入口。

## Phase 2 报告生成

1. **口径确认**：专业映射领域口径，与用户确认一次。
2. **完整执行 industry-policy-report skill 的 Step 1~7**（输出目录 = `<项目>/01-宏观调研报告/`），章节须覆盖：行业规模与结构、**产业链上下游（M2/M3）**、**岗位生态表（M5）**、**传导分析（M9）**、**人才链与进入路径（M10/M11）**、政策解读、区域分布、前景预判与分年级行动。**禁止把底座结论原样复述凑章节**——报告要做增量分析。
3. **定稿改造**：标题《XX领域职业能力调研报告》；可行性建议改写为分年级行动路径（大一~大四）；标注报告链位置（01 宏观）。
4. **区域分布可视化**：优先使用 `assets/china-map/`（部署三件套；value 须有依据；合规自检见 README）。**建议为 M3 增配一张产业链结构图**（ECharts tree/sankey 或 HTML 分层卡片）。
5. **报告标配（v1.3.0）**：整页艺术封面 `.print-cover`（打印第 1 页，见 print-rules.md 第 3 节）+ 导出 PDF 按钮 + 主题切换（红/蓝/绿/橙循环）；打印 CSS 按 print-rules.md（@page margin:0；地图 beforeprint 分流重排）。
6. **交付与校验**：默认只交付 HTML（present_files 预览 + 截图抽查）；仅在用户明确要求时导出 PDF（Edge headless，URL 加 ?cachebust，--virtual-time-budget 30000，--no-pdf-header-footer；pymupdf 渲染抽查地图页）。
7. **记录**：留痕模式启用时追加条目。
