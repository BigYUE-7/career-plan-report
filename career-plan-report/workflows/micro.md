# 微观工作流：02 《个人职业规划书》（B1~B12 · 个人职业决策分析）

> 由 SKILL.md Step 0.5 路由进入。前置条件：Step 0 项目初始化已完成（项目文件夹 + `00-AI工具使用记录.md` 就位）。
> **v0.7.0 重构**：微观方向从"报告生成"升级为**个人职业决策分析**。核心公式：
> `个人规划 = 个人状态 × 行业机会 × 职业偏好 × 能力差距 × 现实约束`
> 决策链（缺一环即不合格）：`个人状态 → 能力画像 → 职业方向 → 岗位画像 → 人岗匹配 → 能力缺口 → 职业决策 → 3~5年路径 → 近期行动 → 备选路线`
> **证据密度原则**：只增加证据、分析、比较、决策、行动；"职业发展具有重要意义"类空话一字不多写。
> 核心主张：**AI 先理解用户是谁，再对照现实世界需要什么，回答"为什么选这个、为什么不选那个、走不通怎么办"，最后给出从今天开始怎么走。**

## 共同前置

- 用户启用了 AI 使用留痕 → 每完成一个阶段，向 `<项目>/00-AI工具使用记录.md` 追加使用记录（日期/软件模型/版本/位置/作用；查不到写"待补充"，禁止编造）；未启用则不做。
- 已有 01 宏观报告 → 直接引用其产业—职业生态结论（`01-宏观调研报告/底座结论.md` 14 节：岗位生态/传导链/进入路径等），不重复检索。
- 问卷未填年级/成绩 → 标"待确认"，路径起点按假设设计并在报告中显式声明假设。

## B1 专业与行业背景

- WebSearch 检索：培养方案核心课程、传统/新兴就业方向、对口职业资格与竞赛。
- Output: 《专业信息卡》——它同时是**选择/新建行业静态预设**（`references/question-bank/industries/<行业>.md`）的依据（v1.2.0：预设是静态资产，不实时生成）。
- Completion Condition: 四项齐备，查不到的显式标注。

## B2 个人信息采集（MD 模板驱动：题目存 MD，HTA 交互，答案写回 MD）

**核心思路**：题目、选项、提示全部写在 **`00-问卷模板.md`**（唯一真源）；`questionnaire.hta` 读取该 MD 动态渲染交互界面；用户填完后答案写回「**已填写 MD**」+「**answers-auto.json**」；Agent 直接读「已填写 MD」即可继续，**无需复制粘贴**。

问卷结构（v1.2.0 起 19 题，按 **8 信息层**分组：基本背景→能力基础→兴趣来源→工作方式→价值偏好→生活目标→现实约束→职业认知与补充；模板见 `references/questionnaire-template.md`）：

- **通用骨架题**（任何专业不换选项，Agent 只可微调提示措辞）：Q1 专业年级 / Q11 成绩学校 / Q3 实践经历 / Q6 工作产出偏好 / Q15 主动投入经历 / **Q19 兴趣原因自述（原因型——"为什么"比"是什么"更能区分兴趣/收入/趋势/从众驱动）** / Q7 环境偏好 / Q12 协作 / Q13 风险 / Q8 价值偏好（multi）/ Q17 理想生活 / Q18 收入预期 / Q9 现实约束（multi）/ Q10 核心约束 / Q16 排斥项（multi）/ Q14 补充。
- **Q2 技能 / Q4 城市 / Q5 方向 = 行业预设槽位**：选项**原样来自** `question-bank/industries/<行业>.md`（静态资产，设计期已多维覆盖：技能方向族/职业路线族/产业集聚城市）。
- **静态预设原则（v1.2.0，必守）**：部署时 Agent 只做"选行业 → 原样合并 → 一次性定稿 MD"，**禁止运行时生成、改写或实时编辑选项**；匹配不到行业预设 → 先把该行业预设写成 `industries/<行业>.md` 存档（成为可复用资产），再合并。
- **静态题库 `references/question-bank/`**（提交后按缺口**挑选已有问题**，不生成新题）：
  - `common/interest.md` A1~A3（兴趣大类→场景下钻→主动投入开放题）
  - `common/work-style-deep.md` W1~W4（自主性/节奏/人际/结果类型四维，与 Q6/Q7/Q12/Q13 交叉验证）
  - `common/career-awareness.md` C1~C2（职业认知度校准："想做什么"≠"知道这个职业是什么"）
  - `common/evidence.md` E1~E3（高光时刻/挫折应对/他人视角——均文字自述，非证明材料）
  - `industries/<行业>.md`（如 ai.md：技能打分预设 + 职业路线族 + 产业集聚城市 + 行业认知度深题）
- **选项规范**：每个选项必须带一句括号释义；每题提供"暂不确定/不想透露"出口；"未勾选"与"暂不确定"都是有效信号；**全卷文字自述即可，不要求任何证明材料**。

**对话补问（v1.2.0 澄清：从静态题库挑选已有问题，单轮 ≤4 题，标注"对话补录"）**：问卷提交后按缺口抽 3~8 题：
- 兴趣未收敛（Q5/Q6 选"暂不确定"或 Q8 勾 ≥4 项）→ common/interest.md
- Q6/Q7/Q12/Q13 信号混杂 → common/work-style-deep.md
- Q5 方向与技能/偏好矛盾，或 Q19 显示趋势/从众驱动 → common/career-awareness.md
- 画像某维度缺自述依据 → common/evidence.md

采集通道（按优先级）：

1. **MD + HTA 闭环（推荐，零依赖）**
   - **Step 1 生成模板**：复制 `references/questionnaire-template.md` 到 `<项目>/00-问卷模板.md`；把 `question-bank/industries/<行业>.md` 的技能/城市/方向预设选项**原样填入 Q2/Q4/Q5**（无匹配行业先建档再合并）；顶部元信息改真实值。
   - **Step 2 部署交互壳**：复制 `assets/questionnaire.hta` 与 `assets/questionnaire-core.js` 到 `<项目>/`；三者 UTF-8 with BOM。
   - **Step 3 用户操作**：双击 `questionnaire.hta` → 填写 → 提交 → 写盘已填写 MD + answers-auto.json。
   - **Step 4 Agent 校验**：收到"问卷已提交"后**必须 Read 已填写 MD 确认存在**；缺失则如实报告并给排查指引，**禁止假装收到答案**；随后结构化落档到 `00-问卷与画像.md`。
   - **Step 4b 打分空值补录**：score 项被勾选但分数为空 → AskUserQuestion 逐项补录（单轮 ≤4 题），标注"对话补录"。
2. **对话直接提问**：AskUserQuestion 分轮提问（单轮 ≤4 题）；选项同样按行业生成。
3. **兜底**：HTA"复制答案"按钮，粘贴回对话后由 Agent 写盘。

Decision: 关键题拒答 → 标"待确认"降精度，禁止编造偏好。

## B3 个人能力画像（自述即依据 · 证据链驱动）

- 六维评分（1-5，可 0.5 步进）：专业技术、数据与 AI 素养、设计与表达、实践与项目、沟通协作、行业认知。
- **评分锚点（v1.2.0 固化）**：1=听说过/接触过；2=能理解基本概念；3=能在指导下完成任务；4=能独立完成常见项目；5=能独立解决复杂问题或有较深经验。
- **自述即依据（v1.2.0，必守）**：依据 = 用户自述 + 问卷回答 + 对话补充 + 已知经历。**禁止要求用户提供证书、截图、代码仓库等证明材料**；每项评分必须引用问卷/对话中的自述内容，写不出具体自述依据就降分或标"待确认"。
- **信号分级**：实践自述（Q3/Q15 主动投入经历/补问 E1~E3）> 行为维度（补问 W1~W4）> 声明式偏好（Q6~Q8）——冲突时以高等级为准并在依据栏注明。
- **Output 固定格式——依据表**：

  | 能力 | 得分 | 置信度 | 自述依据（具体到问卷题目与回答内容） |
  |------|-----:|:---:|------|

  **置信度规则**：高=自述有具体项目/经历支撑；中=有经历但缺复杂度细节；低=仅声明式偏好或描述模糊。依据栏**禁止**"表现良好""有一定基础"类空话。
- Output 另含：雷达图数据 + 一句话画像（最强项 + 最短板 + 总体定位）。
- **推导链义务**：B9 每年度行动必须回溯到本表（标注"对应画像：XX"），形成"短板 → 行动 → 里程碑"闭环。

## B4 职业方向探索（候选方向矩阵）★ v0.7.0 新增

- 从 Q5 意向方向 + Q6 工作方式偏好 + B1 行业扫描，形成 **4~7 个候选职业方向**（不局限于用户勾选——用户没想过的方向也可入榜，但须注明"新增探索"）。
- 每个方向评估三维并成表：**当前匹配**（对照 B3 画像：高/中高/中/低）× **行业潜力**（对照 01 宏观 `底座结论.md` 的传导链与岗位生态）× **准入门槛**（对照 B5/B6 岗位要求与用户现状）→ **推荐星级（1~5）**。
- 输出**四航道结论**：主航道（星级最高）/ 副航道（第二）/ 探索航道（新增且有潜力）/ 暂不建议（说明原因）。
- 这一步回答的是："除了你想的，还有哪些你该考虑的；你想要的里面，哪些其实不适合你。"

## B5 机会清单扫描（分层：核心深度 + 扩展广度）

**扩展清单（广度）**：

- 按"城市 × 行业 × 企业 × 岗位"检索真实招聘信息，**≥15 条，宜多不宜少**；意向城市优先，每城市 ≥3 条（检索不到的城市如实缩减并说明）。
- 每条可溯源（招聘平台/企业官网/权威榜单），注明检索日期。
- 已有 01 产出 → 直接引用 `01-宏观调研报告/底座结论.md`（区域分布、岗位生态、企业生态、进入路径）；否则按需补最小检索。

**核心机会（深度，从扩展清单中选 5~8 条）**，每条必须输出四件套：

1. **岗位要求摘要**：来自真实 JD 的关键要求；
2. **匹配度分析**：对照 B3 六维画像逐维给出匹配程度（条形/百分比均可）；
3. **能力缺口**：明确指出差距最大的 1~2 维；
4. **补齐行动**：未来 6 个月可执行的具体行动（可落地、可验收）。

- 至少 1 条核心机会为"**低匹配·高潜力**"（当前差距大但方向值得投入），并说明为什么值得。
- Completion Condition: 扩展清单全部可溯源 + 核心机会四件套齐备。

## B6 目标岗位画像（聚合同类岗位）★ v0.7.0 新增

- 对 B4 主航道（及副航道）方向，把 B5 扩展清单中同类岗位 **聚合去重**，形成 2~3 张《目标岗位画像》：
  - **核心能力**（JD 高频要求前 5 项，标注出现频次/来源数）
  - **加分能力**（差异化竞争力）
  - **准入门槛**（学历/经验/作品要求）
  - **薪酬行情带**（挂牌区间汇总，标注非成交价）
- 用岗位画像反照用户当前能力（逐项 1~5 粗评），得出交叉优势结论——例如"你的优势不是单一技术，而是 A+B+C 的交叉"。

## B7 人岗匹配与能力缺口矩阵 ★ v0.7.0 新增（报告核心图表）

- 针对主航道目标岗位，输出**能力缺口矩阵**表：

  | 能力项 | 当前 | 目标岗位要求 | 差距 | 优先级 |
  |---|---:|---:|---:|---|

- 差距 = 目标 − 当前；优先级按"差距 × 岗位权重"排 高/中/低。
- 矩阵直接驱动 B9 路径与 B10 行动计划——**每个高优先级缺口必须有对应的补齐行动与验收标准**。
- 同时输出一句话交叉优势结论（什么能力组合是用户独有的）。

## B8 职业选择决策（为什么选 A、为什么不选 B）★ v0.7.0 新增

- 用一段结构化论证回答三个问题：
  1. **为什么选主航道**：能力 × 偏好（Q6~Q8）× 现实机会（B5）× 约束（Q9/Q10）四因子交汇论证；
  2. **为什么暂缓/放弃候选方向**：逐个说明淘汰原因（引用画像与清单证据，禁止"不合适"式空话）；
  3. **走不通怎么办**：触发条件 + 切换动作（如"Y2 结束无署名作品 → 切换到 Plan B 副导演通道"）。
- 与 B11 风险备选衔接。

## B9 3-5 年发展路径（验证期→定位期）

- 分年度（Y1→Y5），**每年度必须有：目标定位 + 行动清单 + 可验收里程碑**，并标注"对应画像：XX"与"对应机会：编号"。
- 阶段命名（禁止"第一年学习、第二年实习"式空泛）：
  - **Y1 验证期**：验证方向是否适合自己（作品/实习/关键技能补齐，验收：≥2 个可展示成果）
  - **Y2 进入期**：进入目标行业（实习/求职/行业网络，验收：相关 offer 或署名作品）
  - **Y3 成长期**：执行者 → 独立贡献者（独立负责项目，验收：署名/数据指标）
  - **Y4 分化期**：**不假设必然晋升**——按 Y1-Y3 结果给出 2~3 条分化路线（如技术路线/管理路线/复合路线），各配触发条件
  - **Y5 定位期**：形成"专业方向 + 核心竞争力 + 职业身份"的明确定位

## B10 近期行动计划（90 天 / 6 个月）★ v0.7.0 新增

- 把 B7 矩阵的高优先级缺口转成**行动表**：行动 → 对应缺口 → 验收标准 → 截止时间（相对时间，如"3 个月内"）。
- 5~8 条为宜，必须"本周就能开始做"的可执行粒度；禁止"提升综合素质"类条目。

## B11 风险与备选路线（四级校准 + 路线树）

- **四级匹配分层**（沿用）：建议进入 / 需补技能 / 慎入 / 不建议近期主线——"慎入"+"不建议"合计 ≥2 条，逐条说明原因（引用画像与清单证据）。
- **路线树**：主航道失败后的分支决策——触发条件 → 副航道 / 探索航道 / 传统接口，每条备选路线注明"保留什么资产、补什么技能"。

## B12 报告生成（16 章结构）

- `templates/plan-template.html` 为样式基座，**章节结构升级为 16 章**（v0.7.0 起）：

  ```text
  01 个人概况            09 能力差距分析（缺口矩阵★）
  02 专业与行业环境       10 我的职业选择（决策论证★）
  03 我的职业画像         11 3~5 年发展路径（验证→定位）
  04 能力雷达与证据       12 年度目标与验收指标
  05 职业兴趣与价值偏好    13 近期行动计划（90 天表★）
  06 职业方向探索（矩阵★） 14 备选路线与风险（路线树★）
  07 目标职业分析（岗位画像★） 15 慎入/不建议方向
  08 人岗匹配分析         16 总结（含数据与来源附录）
  ```

- **图表 5~7 个**（个人报告要有数据感）：① 能力雷达（当前 vs Y3 目标）② 职业方向匹配矩阵（方向×星级）③ 能力差距条形图（当前 vs 要求）④ 城市机会分布（复用 china-map 插件或条形）⑤ 路径时间线 ⑥ 路线树 ⑦ 行动优先级表。至少覆盖 ①②③④。
- HTML 遵守 `references/print-rules.md`（整页艺术封面 `.print-cover` 打印独占第 1 页、@page margin:0 消除每页页脚文件路径、导出按钮标配、beforeprint 图表重排）；ECharts 本地引用、`animation:false`；内置"导出 PDF"按钮。

- 记录：留痕模式启用时追加本阶段条目。
- **反废话自检（提交前必做）**：通读全文，删除所有"随着社会发展""大学生应当提升自己"类无信息量句；每个结论检查是否有证据编号可回溯。
